# CatPhotoApp

A beginner HTML page with cat photos, lists and a form, built while learning the basics of HTML.

Made while working through the [freeCodeCamp Responsive Web Design](https://www.freecodecamp.org/learn/2022/responsive-web-design/) curriculum.

## What it covers

- Headings, paragraphs, links and images (with `alt` text)
- Ordered and unordered lists
- Forms: text inputs, radio buttons, checkboxes and a submit button

## Files

| File | Description |
|---|---|
| `index.html` | The CatPhotoApp page. Open it in any browser |
| `HTML.txt`, `scratch.txt` | My study notes on HTML structure and programming basics |
